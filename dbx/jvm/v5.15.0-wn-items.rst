- Adds support for propagating trace context to the server.

- Adds the ``SrvHostValidator`` interface, which lets you provide a
  custom callback that validates hosts discovered from ``SRV``
  records. To set the callback, use the
  ``ClusterSettings.Builder.srvHostValidator()`` method.

- Reports a write concern error even when the server's
  ``writeConcernError`` response doesn't include an ``errmsg`` field.
  Previously, the driver threw a ``BsonInvalidOperationException``.

- Removes the ``prefixPreview``, ``suffixPreview``, and
  ``substringPreview`` APIs and upgrades the ``libmongocrypt``
  dependency.
